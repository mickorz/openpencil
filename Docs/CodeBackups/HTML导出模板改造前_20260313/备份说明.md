1. `code-panel.tsx`
负责在代码面板中拼装完整 HTML 文档字符串。

负责把当前节点递归转换成 HTML 结构和 CSS 规则。

3. `css-variables-generator.ts`
负责把文档变量系统转换成 CSS 自定义属性，属于 HTML 导出相关依赖。
